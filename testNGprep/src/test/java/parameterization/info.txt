1. @DataProvider - data driven testing
data driven we read data from excel file and read the data and passed it to application
after that we fetech data from application (capture some data)and passed to application -> we use loops
instead of loops we use @DataProvider annotation

we can avoid writing a loop statements
inside data provider we provide test data it has logic and keeps in 2d array
as soon as we read the data from excel file we put them in 2d array then pass data to test method
so that it will repeat multiple times without loop and taking data from excel
can be used for single and multiple test methods
it will just provide data to applications (@Test) methods

we can have multiple data providers in a single class
and we can pass multiple data providers to multiple test methods

the @DataProvider method return type will be a two dimensional array the data type can be String[][], Integer[][] or we can also use Object[][]
sometimes the test data have string, number different combinations so better we use Object[][] data type

it can be a 2D array and returns string or object... like that

excel files and property files -> web automation testing
json files, xml files -> api testing

we need to give name to @DataProvider method and pass that name to @Test method

@Test(dataProvider = "dp")
    void login(String email, String passwd){
        driver.get("https://tutorialsninja.com/demo/index.php?route=account/login");
        driver.findElement(By.xpath("//input[@name='email']")).sendKeys(email);
        driver.findElement(By.xpath("//input[@name='password']")).sendKeys(passwd);
        driver.findElement(By.xpath("//input[@value='Login']")).click();
        boolean status = driver.findElement(By.xpath("//a[text()= 'Edit Account']")).isDisplayed();
        if(status){
            driver.findElement(By.xpath("//a[@class = 'list-group-item' and text()= 'Logout']")).click();
            Assert.assertTrue(true);
        }else{
            Assert.fail();
        }
    }

2. parllel testing -> using XML
 1. created test case
 2. created xml file to run test case

setup method is used to launch browser (chrome/edge) -> passing browser name from xml file
then setup method launch that browser as we are passing browser -> passing parameter at run time
passing a parameter from xml and receiving in method (any methods like @Test, @BeforeMethod, ....)
receive in method at run time
passed browser name as paramater here receive in method (used in setupMethod @BeforeClass())

we use this tag ==== <parameter name="browser" value="chrome"/>

full xml -
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE suite SYSTEM "https://testng.org/testng-1.0.dtd">
<suite name="parallelTesting" verbose="2">
    <test name="MultipleBrowser">
        <parameter name="browser" value="chrome"/>
        <classes>
            <class name="parameterization.paramTest"/>
        </classes>
    </test>
</suite>

    @BeforeClass
    @Parameters({"browser"})
    void setUp(String launcher){
        switch (launcher.toLowerCase()){
            case "chrome":
                driver = new ChromeDriver();
                break;
            case "edge":
                driver = new EdgeDriver();
                break;
            case "firefox":
                driver = new FirefoxDriver();
                break;
            default:
                System.out.println("invalid browser Enter any one chrome/edge/firefox");
                return;
